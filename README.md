# NexusVoice: Personal Voice Assistant

An intelligent, voice-interactive personal assistant running entirely on local hardware, powered by:
- **Speech-to-Text (STT):** [OpenVINO Whisper Base INT8](https://huggingface.co/OpenVINO/whisper-base-int8-ov) optimized for Intel CPUs, Arc GPUs, and NPUs.
- **Large Language Model (LLM):** [LM Studio](https://lmstudio.ai/) serving local GGUF models (such as `qwen2.5-0.5b-instruct` or any model of your choice) via standard OpenAI-compatible API (`http://127.0.0.1:1234/v1`).
- **Text-to-Speech (TTS):** [Qwen3-TTS](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice) for natural, high-fidelity expressive voice generation.
- **Audio Output:** Real-time host speaker playback via `sounddevice` and browser streaming via Web Audio.

Developed in Python adhering strictly to the **Google Python Style Guide**.

## Quick Start: How to Run

### Step 1: Start LM Studio Server
In your terminal, start the LM Studio server (or click **Start Server** inside the LM Studio desktop app):
```powershell
lms server start
```
Load your preferred model (e.g. Qwen 2.5):
```powershell
lms load qwen2.5-0.5b-instruct -y --identifier qwen2.5-0.5b-instruct
```

### Step 2: Run the Assistant Web Server
Launch the server using the bootstrap launcher:
```powershell
.venv\Scripts\python.exe run_server.py
```
Or directly with Uvicorn:
```powershell
.venv\Scripts\uvicorn.exe app.main:app --host 0.0.0.0 --port 8000 --reload
```

### Step 3: Open the Interactive Web Dashboard
Open your web browser and navigate to:
```
http://localhost:8000
```
- Click the **Microphone** button to speak.
- Watch your voice get transcribed in real time by OpenVINO Whisper Base INT8.
- Receive responses generated by your LM Studio LLM.
- Hear the answer spoken aloud via Kokoro-82M TTS!

### Step 4: Next.js + Tailwind CSS Modern Dashboard (Alternative / Next-Gen Frontend)
To run the high-performance modern Next.js 16 + Tailwind CSS v4 dashboard:
```powershell
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with Turbopack fast refresh, live audio waveform canvas, and real-time streaming tokens.

## Interactive Command Line (CLI)

Prefer working directly from the terminal? NexusVoice includes a rich CLI:

### 1. Interactive Microphone Mode (Push-to-Talk)
```powershell
.venv\Scripts\python.exe cli.py --mode voice --duration 4.0 --speaker ryan
```
*Press Enter to speak for 4 seconds, and listen to the assistant's voice response through your speakers.*

### 2. Interactive Text Mode
```powershell
.venv\Scripts\python.exe cli.py --mode text --speaker vivian
```
*Type prompts in the console and listen to synthesized voice replies.*

### 3. Audio File Processing
```powershell
.venv\Scripts\python.exe cli.py --mode file --file path/to/sample.wav
```

### 4. Standalone Text-to-Speech (TTS) Mode
NexusVoice can also be used directly as a standalone, high-fidelity speech synthesizer bypassing LLM inference:

**Single-Shot Speech Synthesis (Play & Save to WAV):**
```powershell
.venv\Scripts\python.exe cli.py --text "Welcome to NexusVoice text-to-speech synthesis." --out speech.wav --speaker af_heart
```
*Tip: Add `--no-play` to synthesize and save directly to disk without playing over speakers.*

**Interactive TTS Console:**
```powershell
.venv\Scripts\python.exe cli.py --mode tts --speaker af_bella
```
*Type text to hear it spoken aloud. Commands include `:voice <persona>`, `:save <file.wav>`, and `:device <cpu/npu>`.*

### 5. Hardware & Accelerator Diagnostic
```powershell
.venv\Scripts\python.exe cli.py --mode info
```

## REST API Reference

The server exposes an OpenAPI schema accessible at `http://localhost:8000/docs`:

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/health` | Subsystem health, OpenVINO devices, LM Studio connectivity |
| `GET` | `/api/devices` | Discovers OpenVINO hardware and audio input/output devices |
| `GET` | `/api/speakers`| Lists supported Kokoro-TTS voices and languages |
| `POST` | `/api/transcribe` | Transcribes an uploaded audio file with Whisper Base INT8 |
| `POST` | `/api/chat` | Sends text message to LM Studio LLM |
| `POST` | `/api/chat/stream` | Streams LLM reply sentence-by-sentence (SSE) |
| `POST` | `/api/chat/tokens` | Streams raw LLM token deltas for word-by-word display (SSE) |
| `POST` | `/api/tts` | Synthesizes text to speech with Kokoro-TTS (returns WAV stream; optional `play_audio`) |
| `POST` | `/api/tts/generate` | **Direct TTS Tool:** Synthesizes text to speech, returns Base64 audio + latency metrics |
| `POST` | `/api/interact` | **Full cycle:** Audio In ➔ STT ➔ LLM ➔ TTS ➔ Base64 Audio Out |
| `POST` | `/api/interact/stream` | Full cycle with SSE token + sentence-audio chunk events |
| `POST` | `/api/record` | Triggers host microphone capture and runs the pipeline |
| `WS` | `/ws/assistant` | Real-time bidirectional WebSocket streaming endpoint (supports `audio`, `text`, and direct `tts` frames) |

## Configuration (`.env`)

You can customize runtime behavior by creating a `.env` file in the root directory:

```env
# Server
SERVER_HOST=0.0.0.0
SERVER_PORT=8000
DEBUG=false

# OpenVINO Whisper STT
STT_MODEL_ID=OpenVINO/whisper-base-int8-ov
STT_DEVICE=NPU
STT_LANGUAGE=en

# LM Studio LLM
LM_STUDIO_BASE_URL=http://127.0.0.1:1234/v1
LM_STUDIO_MODEL=qwen2.5-0.5b-instruct
LM_STUDIO_TEMPERATURE=0.7

# Kokoro-82M TTS (hybrid NPU: prosody + text-encoder on NPU, vocoder on CPU)
TTS_MODEL_ID=hexgrad/Kokoro-82M
TTS_DEVICE=npu
TTS_BACKEND=auto
TTS_OV_MODEL_ID=OpenVINO/Kokoro-82M-int8-ov
TTS_NPU_FULL=false
TTS_SPEAKER=af_heart
TTS_LANGUAGE=a

# Audio Playback
AUTO_PLAY_AUDIO=true
```

### NPU execution (Intel AI Boost)

- **STT (`STT_DEVICE=NPU`):** the Whisper encoder compiles for the NPU
  (decoder on GPU/CPU). Every utterance processes a full 30-second window on
  the NPU — this is the sustained load you see in Task Manager.
- **TTS (`TTS_DEVICE=npu`):** Kokoro is split stage-wise (same approach as
  Intel's AI-PC benchmark). The prosody front-end and text encoder run on the
  NPU via statically-shaped OpenVINO graphs (`app/core/tts_npu.py`); the
  ISTFT vocoder tail stays on CPU torch. TTS encoding takes milliseconds per
  sentence, so expect brief NPU spikes rather than a sustained plateau.
- **First run is slow** (one-time NPU compilation, minutes), then fast:
  compiled graphs and the NPU compiler cache persist under
  `model_artifacts/kokoro_npu/` (git-ignored).
- **Fidelity tradeoff:** `TTS_NPU_FULL=true` additionally forces the
  transformer stage onto the NPU for maximum NPU load, at measurably lower
  fidelity (0.51 vs 0.98 waveform correlation against the CPU reference).
  The default hybrid keeps quality at ~0.98 with identical speech durations.
